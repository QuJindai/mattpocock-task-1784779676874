# V4.5 Night Apartment Atmosphere Design

## Goal
在不改变 Alicia 模型、动作姿态、标准/近景取景算法和交互接口的前提下，把当前暗化日间客厅改造成接近目标效果图的暖色夜景公寓。

## Approved Scope
- 保留 Alicia Solid 默认模型与自定义 VRM URL。
- 保留 V4.4 自然挥手、标准取景和真实近景。
- 背景改为完全程序化 CSS 2.5D 夜景公寓，不依赖远程图片。
- 增加窗外冷色城市、暖色台灯、沙发和前景层次。
- 调整 Three.js 灯光为暖色主光、低强度环境光和冷色轮廓光。
- 新增夜景氛围验收，继续运行近景、挥手和三场景回归。

## Visual Target
- 整体平均背景亮度明显低于 V4.4，但人物面部保持可读。
- 左侧存在暖色光源区域，右侧窗外存在冷蓝城市区域。
- 背景不是平铺照片，具备墙面、窗、沙发、灯、地面和前景遮挡的空间层次。
- 捕获模式继续隐藏全部 UI，不影响像素边界测试。

## Implementation Boundary
只修改单文件页面中的 CSS 背景层、背景 DOM、灯光颜色/强度和构建标记。模型、动作、骨骼参数、自动取景算法不做任何修改。

## Acceptance
1. buildId 为 `visual-alicia-v4-5-20260805`。
2. 标准待机、自然挥手、真实近景现有硬门全部通过。
3. 夜景背景页面中心和窗区亮度分布满足冷暖差异门。
4. 页面不再请求 Unsplash 或其他远程背景图片。
5. 人物平均亮度保持在既有允许范围内。
